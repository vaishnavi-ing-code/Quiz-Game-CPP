# 🎮 Quiz-Game-CPP
📝 Description: A simple and interactive QUIZ GAME BUILD WITH C++ that allows users to test their knowledge through multiple-choice questions from different categories and difficulty levels.

# 🎇 Feature
* 🧮 4 categories
. Mathematics
. Science
. Programming
. General Knowledge
* 📊 3 Difficulty Levels
. Easy
. Medium
. Hard
* ❓ 360 QUESTIONS in total
* 🎲 Randomly selected questions
* 💿 4 multiple-choice options
* 🏆 Automatic score calculation
* 💾 Score saved in a text file
* 📂 Questions stored separately for easy editing
* 🔄 Replay the quiz

# 📁 Project Structure
Quiz-Game/
|
|______________ main.cpp____________ 📄 Contains the main program and complete quiz logic.
|______________ questions.txt____________ 📄 Stores all quiz questions, categories, difficulty level, options, and correct answer
|______________ scores.txt_____________ 📄 Stores the player's quiz results and scores.

# 📝 Question Format
Questions are stored using | as a separator:
Category|Difficulty|Question|Option1|Option2|Option3|Option4|CorrectAnswer

# ▶️ How to Run
1. Compile
 g++ main.cpp -o quiz
2. Run
 .\quiz.exe
Make sure questions.txt is in the same project folder as the program.
